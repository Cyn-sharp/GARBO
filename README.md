# GARBO
GARBO 2.0 will be redesigned as a university-based waste management and student engagement web application rather than a barangay/LGU garbage collection system. The main goal is to encourage students to properly dispose of and segregate their waste by making responsible waste behavior more convenient, interactive, and rewarding. Students can use GARBO to scan QR codes placed on campus garbage bins, identify the correct disposal category, earn GARBO points, complete daily environmental missions, maintain eco-streaks, compete through individual/department leaderboards, earn badges and rewards, find nearby garbage/recycling bins through a campus map, report overflowing or problematic waste areas, and view their personal environmental impact. We can also integrate an AI waste scanner where students take a photo of their trash and GARBO recommends the proper disposal category. Meanwhile, the university gets an admin dashboard for monitoring student participation, waste reports, recycling activity, hotspots, challenges, and overall campus waste behavior. Since this will be a mobile-first web app, students can access it through their phones without installing a native application, while administrators can use the same system on desktop. Suggested tech stack: Next.js/React for the frontend, Tailwind CSS for UI, Node.js/Next.js API for the backend, PostgreSQL with Supabase for the database and authentication, Google Maps or OpenStreetMap for the campus map, QR codes for bin identification and verification, and an AI vision API/model for waste classification. We can deploy the frontend/backend using Vercel and host the database through Supabase. The main concept is basically: Student encounters waste → GARBO helps identify it → student finds the correct bin → disposal is verified → student earns points → competes/completes missions → develops better waste habits → university gets useful data to improve campus waste management.
